# Task 2 — Mini Social Media Platform

## Requirements
- Node.js 18 or newer
- npm

## Run
```bash
npm install
npm start
```

Open http://localhost:3002

The SQLite database is created automatically on first run. Register an account to use account-only features.

## Main features
- Registration and login
- User profiles and editable bio
- Create posts and add comments
- Like/unlike posts
- Follow/unfollow users
- SQLite persistence and sample feed
